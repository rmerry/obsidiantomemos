# ObsidianToMemos

Very simple script I wrote to import a raw [Obsidian](https://obsidian.md/) vault into [Memos](https://usememos.com/). This code is **absolutely not production ready** and has had no testing---it worked for me, might work for you.

## Usage

```sh
go run main.go <MEMOS-URL> <MEMOS-ACCESS-TOKEN> <VAULT-DIR> ```
